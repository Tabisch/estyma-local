Cloud monitoring

Poll the Estyma cloudReads the values the cloud shows, to compare them with the local ones.

Polls the Estyma cloud with the account from the container environment (ESTYMA_EMAIL / ESTYMA_PASSWORD) and writes cloud-*.jsonl next to the other logs. The credentials never pass through this page. The latest cloud values are shown on the monitor page while this is on.

Cloud connection

Answer when the cloud is slowIf the cloud has not replied in time, or replies with an error, the controller gets a normal local reply instead.
Loading…

Used in proxy and hybrid mode. The controller waits about 14 s for a reply; when it gets none it skips about 80 s before it reports again. The local reply asks for the usual registers, so the controller does not notice. The cloud still receives the report; its late reply is only logged.

Logs

Delete old logs automaticallyRemoves .jsonl log files that were last written more than the given number of days ago.
Loading…

Checked right after a change and then every hour. Applies to exchanges-*, cloud-* and writes-*.jsonl; state.json and registers.json are never deleted. The monitor reloads its charts from the logs on restart, so keep at least 2 days.
